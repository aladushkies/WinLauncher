# WinLauncher — план для разработчика

Цель: лаунчер для Samsung Galaxy Tab A 9.7 (SM-T555), Android 7.1.1 (API 25), 1024×768, с интерфейсом в стиле Windows 10, многозадачностью и оконным менеджером.

## 1. Ограничения платформы (важно)
Обычное приложение не может управлять окнами чужих приложений. На Android 7.1.1 без root/system-прав:
- ВАЖНО (уточнено): на SM-T555 с включённой опцией разработчика «Изменение размера в многооконном режиме» (force_resizable_activities) работает Samsung Pop-up View — чужие приложения открываются в плавающих окнах. Лаунчер запускает их через скрытый `ActivityOptions.setLaunchStackId(2)` (freeform) + `setLaunchBounds()`; точное поведение нужно проверить на устройстве;
- доступны: split-screen (`FLAG_ACTIVITY_LAUNCH_ADJACENT`, только когда лаунчер сам в split) и pop-up view Samsung (из меню приложения, программно не вызывается);
- список запущенных чужих задач: `getRecentTasks()` отдаёт только свои; для остальных — `UsageStatsManager` (разрешение «Доступ к данным об использовании») или `AccessibilityService`.

Поэтому архитектура трёхуровневая:
1. **Собственные окна (полный контроль)** — встроенные мини-приложения и виджеты (AppWidgetHost) внутри оконного менеджера лаунчера: перетаскивание, ресайз, свернуть/развернуть, snap, z-порядок, панель задач.
2. **Сторонние приложения** — запуск через `startActivity` + `LAUNCH_ADJACENT` + `setLaunchBounds` (сработает при split-screen или на прошивке/root с freeform).
3. **Опционально (root / ADB)** — `adb shell settings put global enable_freeform_support 1` + кастомная прошивка с freeform: тогда `setLaunchBounds` реально позиционирует чужие окна. Код менять не нужно.

## 2. Архитектура
```
MainActivity (HOME, singleTask, sensorLandscape)
 ├─ Desktop FrameLayout
 │   ├─ GridLayout        — иконки рабочего стола
 │   ├─ WindowLayer       — менеджер окон (список WindowView, фокус, z-order)
 │   │    └─ WindowView   — заголовок + контент + ручка ресайза
 │   └─ StartMenu         — список приложений + поиск
 └─ Taskbar               — Пуск | кнопки окон | часы
```
- `WindowLayer`: `open/focus/minimize/close/toggleFromTaskbar`, колбэк `onChanged` для панели задач.
- `WindowView`: drag за заголовок, двойной тап = развернуть, перетаскивание из развёрнутого состояния возвращает размер, snap к левому/правому краю (половина экрана) и к верху (максимизация), ресайз за правый нижний угол.
- Встроенные приложения: `Apps.kt` (Блокнот, Калькулятор, Браузер на WebView, Проводник, Часы) — любой `View`.

## 3. Спецификация интерфейса
- Панель задач 48dp, цвет #1F1F1F (94% непрозрачности), кнопка Пуск «⊞» слева, часы и дата справа; активное окно подсвечено, свёрнутые — полупрозрачные; долгий тап по кнопке = закрыть.
- Заголовок окна 36dp, активное #0078D7, неактивное #6B6B6B, кнопки — ⁠свернуть/развернуть/закрыть по 46dp (удобно пальцем).
- Меню Пуск 340×460dp, поиск по приложениям, список всех установленных приложений с иконками.
- Рабочий стол: иконки 88×84dp, подпись с тенью, обои системные.
- Ориентация: альбомная.

## 4. Roadmap
**v0.1 (в архиве)** — рабочий стол, панель задач, Пуск, оконный менеджер, 5 встроенных приложений, запуск сторонних.
**v0.2** — AppWidgetHost: виджеты Android в окнах; «Корзина», контекстное меню (ПКМ = долгий тап) на рабочем столе и иконках; закрепление приложений на панели задач; обои/акцентный цвет в настройках.
**v0.3** — Центр уведомлений (NotificationListenerService), быстрые настройки (Wi-Fi, яркость, громкость), системный трей.
**v0.4** — Alt+Tab-подобный переключатель и Task View (сетка миниатюр окон), горячие клавиши для Bluetooth-клавиатуры (Win, Alt+Tab, Win+←/→), поддержка мыши (hover, правая кнопка).
**v0.5** — Отслеживание чужих приложений: UsageStatsManager / AccessibilityService → кнопки на панели задач для чужих задач, переключение через `ActivityManager.moveTaskToFront` (нужно `REORDER_TASKS`).
**v1.0** — Файловый менеджер с открытием файлов (FileProvider), настройки лаунчера, иконки-паки, тёмная/светлая тема, сохранение раскладки окон.

## 5. Тестирование
- Эмулятор API 25 (tablet 1024×768) и реальный SM-T555.
- Проверить: поворот экрана (configChanges), нехватка памяти (SM-T555: 2 ГБ ОЗУ — ограничить число WebView), кнопка «Домой», запуск после перезагрузки.

## 6. Сборка
Открыть папку в Android Studio (Hedgehog и новее) → Sync → Build > Build APK → установить, затем кнопка «Домой» → «Всегда» выбрать WinLauncher. Установка из неизвестных источников: Настройки → Безопасность.
